HAZRA BARI VIRTUAL DURGA MANDIR 2026

Files required in the GitHub repository:
1. app.py
2. maa_durga.png
3. requirements.txt

Streamlit Cloud:
- Main file: app.py
- Python dependencies: requirements.txt

The app uses a local SQLite file named mandir.db. It is suitable for a prototype/demo. Streamlit Cloud's local filesystem is not a permanent production database, so permanent multi-user data should later be moved to a hosted database.

The user's Maa Durga image should be uploaded to the repository with the exact filename:
maa_durga.png

All Mandir wallet balances, Chadhawa prices and cashback values are virtual only.
